# Interview Prep Site

This is the initial skeleton of a private interview preparation website.

## Folder structure

- `index.html` — root entry page of the site.
- `assets/css/global.css` — shared global styles.
- `assets/js/` — shared scripts:
  - `app.js` — main app initialization.
  - `navigation.js` — site navigation logic.
  - `progress-store.js` — tracks preparation progress.
  - `notes-store.js` — stores user notes.
- `data/topics.js` — list of topic IDs, names, and folder paths.
- `topics/` — one folder per interview topic, each with its own `index.html`, `style.css`, and `script.js`.

## Status

This currently contains only an initial skeleton — no real content, styling, or logic yet.
